# 招牌YA 一頁式銷售網頁

靜態網站，可直接放上 GitHub Pages。

## 上線步驟
1. 在 GitHub 建一個新的 repository（例如 `luckya-page`）。
2. 把本資料夾內所有檔案（index.html、demo-*.html、support.js、thumbs/）上傳到 repository 根目錄。
3. Settings → Pages → Source 選 `main` 分支、資料夾選 `/ (root)`，儲存。
4. 幾分鐘後可用 `https://<你的帳號>.github.io/<repo 名稱>/` 開啟。

## 檔案說明
- `index.html`：主銷售頁（招牌YA）
- `demo-cafe / nail / pet / gym / noodle / cram .html`：六個示範店家網站，從主頁作品區另開視窗連過去
- `thumbs/`：作品區使用的頁面快照（更新範例頁後需重新截圖替換）
- `support.js`：頁面執行所需的程式檔，請勿刪除

## 修改內容
文字直接編輯對應的 .html 檔即可。LINE 與 Email 出現在 index.html 的結尾區塊。
